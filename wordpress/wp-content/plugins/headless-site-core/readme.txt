Connects WordPress posts and pages to the Next.js frontend in this repository.

== Features ==

* Public site-settings REST endpoint at /wp-json/headless/v1/site
* Canonical Next.js path on post and page REST objects
* Lightweight SEO title and description fields
* Automatic Next.js route revalidation when published content changes
